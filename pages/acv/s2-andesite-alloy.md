安山岩鉱石は、Createにおいて最も使用される中間素材であるため、生産フローの設計が極めて重要である。本ドキュメントでは、安山岩合金を可能な限り低コストで無限生産できるフローを提案し、各企業のプラント設計時の道標となることを目的とする。

## Flow_1

```flow
title: Main_1
丸石（丸石製造機）
↓ 製粉
**砂利**
↓ 製粉
**火打石**
```

```flow
title: Main_2
**マグマ**（鍾乳抽出）
```

```flow
title: Main_3
**鉄インゴット**・**ポピー**（ゴーレムトラップ）
↓ クラフト
**鉄塊**
```

## Flow_2

```flow
title: Main
**火打石**・**砂利**・**マグマ**
↓ 圧縮
**安山岩**
```

```flow
title: Sub_1
砂利
↓ 一括洗浄
**火打石%**・**鉄塊%**
```

```flow
title: Sub_2
砂利
↓ 粉砕
**砂**・**火打石%**・**粘土%**
↓ 一括憑霊
**ソウルサンド**
↓ 一括洗浄
**ネザークォーツ%**・**金塊%**
```

## Flow_3

```flow
title: Main
**安山岩**・**鉄塊**
↓ 混合
**安山岩合金**
```

## 副産物

- 砂
- ソウルサンド
- 粘土%
- ネザークォーツ%
- 金塊%

※ 末尾に%が付いているものは、確率生成
