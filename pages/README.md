# ページの書き方

ポータルのページは、すべてこのフォルダのMarkdown（`.md`）ファイルです。
フォルダにファイルを追加して `main` ブランチにpushすると、数分でサイトに自動で反映されます。

## フォルダ

| フォルダ | タイトル画面のボタン | 一覧の並び順 |
|---|---|---|
| `news/` | お知らせ | `date` の新しい順 |
| `diary/` | 日記 | `date` の新しい順 |
| `orgs/` | 主要企業及び団体 | `order` の小さい順 |
| `acv/` | アーカイブ | `category` ごとに分けて表示 |
| `_templates/` | （サイトには出ない） | 雛形置き場 |

- ファイル名がそのままURLになります（`pages/news/season3-start.md` → `#/news/season3-start`）。**英数字とハイフン**で付けてください。
- `_` で始まるファイルと `README.md` はサイトに出ません。

## 手順

1. `_templates/` から雛形（`news.md` / `diary.md` / `org.md` / `subpage.md`）をコピーする
2. 追加したいフォルダに置いて、ファイル名を変える
3. 先頭の `---` で囲まれた部分（フロントマター）と本文を書き換える
4. commitしてpushする（GitHubのWeb画面の「Add file → Create new file」からでもOK）

## フロントマター

ファイルの先頭に、ページの情報を `項目: 値` の形で書きます。

```markdown
---
title: Season 3 開幕のお知らせ
date: 2026-10-05 21:00
tag: 運営
author: いちのすけ
---
```

| 項目 | 必須 | 説明 |
|---|---|---|
| `title` | ○ | ページのタイトル |
| `date` | お知らせは○ | `2026-10-05 21:00` の形式 |
| `tag` | | お知らせのタグ（色は `config/site.json` の `tagColors`） |
| `author` | | 作成者 |
| `summary` | | 一覧に出る一行の説明 |
| `order` | | 一覧の並び順（小さいほど上） |
| `parent` | | 子ページにするときの、親ページのファイル名（`.md` なし）。同じフォルダに置く |
| `icon` | | タイトル横に出る絵文字 |
| `mark` / `color` | | 画像がないときのアイコン文字と色（`stone` `green` `blue` `red` `purple` `gold` `aqua`） |
| `thumb` | | 一覧のアイコン画像（このファイルからの相対パス） |
| `cover` | | ヘッダー画像。ページ上部と、一覧の左のアイコンに使う（なければ本文の最初の画像） |
| `toc` | | `true` で見出しから目次を自動で作る |
| `excerpt` | | 一覧の3行目に出す文。省略すると本文の先頭20文字 |
| `layout` | | `corporate` で企業サイト風の表示にする（下記） |
| `eyebrow` / `catch` / `lead` / `facts` | | 企業サイト風のときのヒーロー部分（下記） |
| `draft` | | `true` で非公開 |
| `category` | アーカイブのみ | `news` / `seasons` / `orgs`（アーカイブ一覧の分類） |

`#` で始まる行と、値のあとの ` # ...` はコメントとして無視されます。

## 本文の書き方

普通のMarkdown（GitHubと同じ書き方）です。

| 書きたいもの | 書き方 |
|---|---|
| 見出し | `## 大見出し` / `### 中見出し` / `#### 小見出し`（`#` 1つはページタイトル用なので使わない） |
| 太字（黄色で表示） | `**文字**` |
| 箇条書き | `- 項目` / 番号付きは `1. 項目` |
| 表 | `\| 見出し \| 見出し \|` と `\|---\|---\|` |
| 引用 | `> 文章` |
| 区切り線 | `---` |
| リンク | `[文字](https://example.com)` |
| ほかのページへのリンク | `[UDE HD.](../acv/ude-hd.md)`（このファイルからの相対パス） |
| 画像 | `![説明](../../assets/img/xxx.webp "キャプション")` |
| 画像を並べる | 画像を空行なしで続けて書くとギャラリーになる |

### 枠（コールアウト）

GitHubのアラート記法がそのまま使えます。

```markdown
> [!NOTE]
> メモ

> [!TIP]
> ヒント

> [!IMPORTANT]
> 重要

> [!WARNING]
> 注意

> [!CAUTION]
> 警告
```

### 生産フロー図

コードブロックの言語に `flow` を指定すると、インベントリ風の図になります。
`title:` で見出し、`↓ 工程名` で矢印を書きます。続けて書いたフローは横に並びます。

````markdown
```flow
title: Main
丸石（丸石製造機）
↓ 製粉
**砂利**
```
````

## 画像

`assets/img/` の下にフォルダを作って置きます（例: `assets/img/season-3/map.webp`）。
ファイル名は英数字にして、横幅1600px程度に縮小しておくと表示が軽くなります。

## 子ページ

`parent` を書いたページは一覧には出ず、親ページの下に「関連ページ」として自動で表示されます
（親ページの本文からリンクしている場合は、二重には出ません）。

## 一覧画面の表示

各ボタンの先は、ワールド選択画面風の「ページを選択」画面です。1件ごとに次の3行が出ます。

1. `title`
2. `author`（`date`）
3. 本文の先頭20文字（文字数は `config/site.json` の `list.excerptLength`）

上の入力欄で、タイトル・作成者・本文の先頭（`list.searchTextLength` 文字まで）を検索できます。子ページは検索したときだけ表示されます。

## 日記（Discord BOT向けの仕様）

- 置き場所: `pages/diary/`
- ファイル名: `YYYY-MM-DD.md`（例: `2026-10-05.md`）
- フロントマター: `title` と `date`（`YYYY-MM-DD HH:MM`）は必須、`author` はBOT名
- 本文: 普通のMarkdown（雛形は `_templates/diary.md`）
- 投稿方法: `main` ブランチにcommit・pushする（GitHub APIの「Create or update file contents」でも可）。pushから1分ほどで公開される
- 公開範囲: サイトもリポジトリも誰でも読めるため、**個人情報・IPアドレス・招待リンクなどはBOT側で伏せてから投稿する**


## 企業サイト風の表示（`layout: corporate`）

主要企業及び団体のページ向けです。雛形は `_templates/org.md`、実例は `orgs/q1.md` を見てください。

| 書き方 | 表示 |
|---|---|
| フロントマターの `eyebrow` / `title` / `catch` / `lead` | ページ上部のヒーロー（社名の上の小文字・社名・キャッチコピー・一文） |
| `facts: 設立=Season 1 \| 代表=キチゲ` | ヒーロー内の数字・項目の帯（`項目=値` を `\|` で区切る） |
| `color` / `cover` | ヒーローの色・背景画像 |
| `## MESSAGE / CEOメッセージ` | 英字の小見出し付きのセクション。英字部分はページ上部のメニューにも並ぶ |
| `### 🌾 seqtor.1 ── １次産業セクター` | カード（同じセクション内で横に並ぶ）。`──` の後ろは小見出し |
| `- q1.farm：栽培所（建設予定）` | 施設リスト。`：` の前が名前、`（建設予定）` などはバッジ |
| 番号付きリスト | 沿革のタイムライン。`**Season 3　開始**` のように太字だけの項目は節目として強調 |
| `\| 項目 \| 内容 \|` の表 | 会社概要の表 |
| 短い引用（`> q1 CEO　キチゲ`） | 右寄せの署名 |
